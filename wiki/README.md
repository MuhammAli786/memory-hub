# Wiki

The wiki is the curated knowledge layer. Every substantive page uses the template in `templates/page.md` and belongs in one of these folders:

```text
concepts/       ideas, methods, and topics
comparisons/    evidence-backed comparisons
entities/       systems, tools, and organizations
people/         sourced dossiers
projects/       active or historical project state
sources/        summaries of individual raw sources
source-summary/ compatibility folder for source summaries
```

`index.md` is the catalog. `activity-log.md` is append-only and records material processing. `log.md` is reserved for automated ingestion runs and is not a knowledge page.
