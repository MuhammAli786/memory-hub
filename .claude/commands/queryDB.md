# QueryDB

1. Search curated wiki pages and read relevant pages fully.
2. Use L1 for decisions, L0 for original wording, L2 for a work-period account.
3. Use TencentDB code graph or Graphify for callers, ownership, paths, and
   cross-file/page relationships.
4. Check graph revision and generation time, then open current source before a
   consequential implementation decision.
5. State evidence, freshness, contradictions, uncertainty, and inference.

Treat empty results as a possible scope, access, or readiness problem before
claiming information is absent.
