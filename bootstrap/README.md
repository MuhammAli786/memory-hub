# Clean Bootstrap State

This directory exists so a new user starts with the same operating structure
without inheriting another user’s history.

Never import another person’s raw exports, conversation captures, wiki pages,
activity log, priorities, task data, memory database, graph snapshot, model
cache, panel registry, or local configuration into this repository.

Use the templates below only to initialize an empty system. Importing a user’s
own records is a local, reviewed migration outside Git.
